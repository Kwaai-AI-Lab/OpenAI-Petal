## Available Alternatives

### Option 1: Manual Installation
For advanced users comfortable with Python package management:

```cmd
# Clone the repository
git clone https://github.com/Kwaai-AI-Lab/OpenAI-Petal.git
cd OpenAI-Petal\Installer\windows

# Install manually
pip install -e .
```

### Option 2: Use Linux with WSL2
Install Windows Subsystem for Linux 2 and use the stable Linux installer:

```bash
# In WSL2 Ubuntu
curl -fsSL https://raw.githubusercontent.com/Kwaai-AI-Lab/OpenAI-Petal/main/Installer/linux/linuxinstaller.sh | bash
```

### Option 3: Docker (Cross-platform)
Use the containerized version (if available).
